🏛️ 적용한 아키텍처 및 디자인 패턴

MSA · EDA · DDD · Hexagonal · Outbox · API Gateway
서비스 분리와 이벤트 기반 통신, 도메인 중심 설계
  • MSA(마이크로 서비스 아키텍처): 서버별 역할 분리를 통한 효율적인 자원 활용 및 느슨한 결합 구조 적용
  • EDA(이벤트 기반 아키텍처): Redis Stream을 활용한 이벤트 기반 통신을 통해 분산 시스템 간 데이터 동기화
  • DDD 기반 도메인 모델 설계: 비즈니스 본질에 집중
  • Hexagonal Architecture(Port & Adapter): 외부 의존성 최소화 및 유지보수성 향상
  • Outbox 패턴: 이벤트 발행 시 각 서버별 데이터 정합성 보장
  • API Gateway 패턴: 단일 진입점 제공 및 인증·권한 검증 로직 구현

🔒 보안성 및 사용자 편의성

JWT · OAuth2 · SMTP · Bcrypt
유저 경험(UX)과 보안성을 고려한 설계
  • 키셋 방식 페이지네이션 적용: 데이터 조회 최적화를 통한 성능 향상 및 일관된 UX 제공
  • JWT: 세션 대신 Stateless 인증 방식 채택으로 서버 메모리 절약 및 RTR 방식을 통한 보안성 향상
  • OAuth2: 카카오 로그인 등 OAuth2 인증 방식 채택을 통한 UX 최적화
  • 이메일 인증 (SMTP): 회원가입 시 이메일 인증 기능 구현으로 보안성 향상 및 이메일 무단 사용 방지
  • Bcrypt 암호화: 회원가입 시 패스워드 Bcrypt 암호화로 보안성 향상

💬 실시간 채팅 기능 구현

Nest.js · WebSocket · Redis Pub/Sub
다중 서버 환경 실시간 양방향 채팅
  • Nest.js 활용: 비동기 Non-Blocking 구조의 Nest.js 프레임워크로 실시간 채팅 성능 향상
  • WebSocket 통신: WebSocket을 통한 양방향 통신 및 실시간 채팅 기능 구현
  • Redis Pub/Sub: 다중 서버 환경에서 실시간 채팅 구현을 위해 Redis Pub/Sub 활용
